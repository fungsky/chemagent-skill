# 球形硅粉中试工艺（溶胶-凝胶路线）

> 调研卡片 · 更新：2026-09-01 · 放大参数为工程建议，需工厂试验验证；部分数据来自文献（见文末）。

## 中试目标与规模
- 规模：100–500 L 反应釜，单批 1–10 kg 级球形二氧化硅微球
- 目标：验证粒径可控性（180–380 nm）、单分散性（CV≤5%）、批次一致性
- 文献参考：中试级连续生产介孔二氧化硅可达 1 kg/天（RSC）

## 工艺流程
配料计量（乙醇/水/氨水）→ TEOS 计量滴加 → 恒温搅拌反应 → 陈化 → 固液分离 → 醇洗/水洗（乙醇回收）→ 干燥 → 解聚分级 → 质检包装

## 主要设备
| 设备 | 规格/要求 | 放大要点 |
|---|---|---|
| 主反应釜 | 100–500 L，搪玻璃/316L，夹套冷却，密闭+氮封 | 防爆（乙醇）、耐氨碱 |
| 搅拌 | 框式/锚式+挡板，变频 | 保持叶端线速度 ~0.5–1 m/s（非转速），避免高剪切破乳团聚 |
| TEOS 加料 | 计量泵连续滴加（液下） | 滴加速率恒定，控制成核数量 |
| 温控 | 夹套循环水 20±2 ℃ | 水解放热，冷却能力匹配滴加速率 |
| 固液分离 | 碟片/管式离心机 | 100–400 nm 纳米颗粒难过滤，实验室离心无法直接放大 |
| 洗涤 | 2–3 级逆流醇洗→水洗 | 洗至电导率达标，乙醇精馏回收循环 |
| 干燥 | 喷雾干燥 / 真空带式 / 冷冻干燥 | 喷雾产率高但粒径分布变宽、易空心化；需后解聚 |
| 解聚分级 | 气流解聚 + 分级 | 消除干燥硬团聚 |

## 关键放大控制点
1. 加料方式：实验室一次性倾倒 → 中试计量泵连续滴加；必要时改「溶胶种子法」分段生长
2. 混合：按叶端线速度恒定换算转速；加料点与搅拌匹配
3. 温度：20 ℃ 恒温，水解放热需夹套冷却
4. 氨浓度：对粒径最敏感，密闭精确计量防挥发
5. 洗涤纯化：逆流洗涤至电导率达标（电子级杂质 ppb 级）
6. 干燥防团聚：控制固含量与温度梯度；高价值批次用冷冻干燥
7. 一致性：首批 DOE（氨浓度×滴速×水比）建立粒径模型

## 中试验收指标（目标值）
- 粒径 D50 180–380 nm 可调，批内/批间波动 ≤5%
- 单分散性 CV ≤5%；无定形率 ≥95%
- 收率 ≥80%（需测算）；杂质按目标规格

## 安全与环保
- 乙醇防爆：防爆电气、氮封、静电接地、浓度报警
- 氨水：MSDS 管理、局部通风、废气稀酸吸收
- 废液：乙醇精馏回收 + 废水处理

## 风险与对策
- 粒径分布变宽/团聚 → 优化滴速与搅拌、改种子法
- 收率低（离心损失）→ 评估絮凝或膜分离
- 喷雾干燥空心化 → 控制进料固含量与温度梯度
